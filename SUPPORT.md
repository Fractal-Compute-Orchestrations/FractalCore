# Support and Community

This document provides resources for obtaining technical support, reporting operational issues, and engaging with the FractalCore engineering team.

---

## Community Support Channels

- **GitHub Issues**: Use GitHub Issues for bug reports and targeted feature requests. Please consult existing open and closed issues before opening a new ticket.
- **GitHub Discussions**: For architectural questions, deployment advice, and general community discussion.
- **Technical Documentation**: Review the [docs/](docs/) directory for detailed system architecture, REST API references, and deployment guides.

---

## Security Vulnerabilities

Please do not disclose potential security vulnerabilities through public issue trackers. Follow the procedures defined in [SECURITY.md](SECURITY.md) to submit a confidential report to `security@fractalcompute.io`.

---

## Commercial and Enterprise Support

For enterprise SLA inquiries, custom cloud cluster deployments, or dedicated integration assistance, contact the maintainers at `contact@fractalcompute.io`.
