# Support

Thank you for using FractalCore! We want to make sure you have the best experience possible.

## How to get help

- **GitHub Discussions**: For general questions, ideas, and sharing your experience.
- **GitHub Issues**: To report bugs or request new features.
- **Documentation**: Check our [docs/](docs/) directory for detailed guides.

## Security Issues

If you find a security vulnerability, please do **not** open a public issue. Refer to our [Security Policy](SECURITY.md) for reporting instructions.
