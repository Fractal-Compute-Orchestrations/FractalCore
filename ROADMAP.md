# FractalCore Roadmap

Our vision is to become the leading open-source orchestration layer for Federated Learning.

## Q3 2026: Stability & Performance
- [ ] **Adaptive Aggregation**: Dynamically adjust `MAX_CLIENTS` based on network health.
- [ ] **Performance Benchmarking**: Automated suites to measure aggregation latency.
- [ ] **Database Abstraction**: Support for PostgreSQL/MongoDB alongside Firestore.

## Q4 2026: Privacy & Security
- [ ] **Differential Privacy**: Integrate DP noise into the aggregation layer.
- [ ] **Secure Multi-Party Computation (SMPC)**: Experimental support for encrypted weight aggregation.
- [ ] **OIDC Support**: Integration with professional identity providers (Okta, Auth0).

## 2027: Enterprise Scaling
- [ ] **Kubernetes Operator**: Native K8s management for FractalCore instances.
- [ ] **Web UI 2.0**: Advanced visualization of global model convergence and client participation maps.
- [ ] **Cross-Framework Support**: Official SDKs for PyTorch Mobile and CoreML.
